CaliGo, rewritten as a native Android app.

## What's new

- **Native**: the whole app is rewritten in Kotlin and Jetpack Compose, in place of Flutter. Everything works as before and looks the same: the same screens, type, colors and light and dark themes.
- **Faster and lighter**, measured on a Pixel 10a with the same cards and stops on the home screen: it opens in 115 to 128 ms instead of 177 to 180 ms, about 30 % faster, and holds about 116 MB of memory instead of 162 to 171 MB, about 30 % less. The download drops from 19.2 MB to 2.4 MB.
- **One APK for every phone**: the `arm64-v8a` and `armeabi-v7a` files are the same, under the two names older versions look for.
- **Fixes**:
  - Cards: a card number already saved is refused, a new card goes at the end of the list, the number takes digits only, and a failed reorder or delete says so, a failed reorder putting the order back.
  - Balances: the last known balance notice no longer flashes away, and refreshing one card waits for a refresh of all of them.
  - Stops: the home shows it is loading while its stops load, saved stops show at once while closest first waits for the location, changes made while a list loads are kept, an area with no buses around counts as missing, and a stop already saved or a location that did not come in time each get their own message; the stop details close as soon as a stop is saved.
  - Lines: routes and hours that fail to load are asked again instead of staying missing until a restart, a route failure no longer reads as an arrivals failure, a line without hours is named once, and the same buses and routes are asked for less often.
  - Map: a kept tile is shown when the network fails, more tiles are kept, the cache stays within its size during a run, and the location button no longer spins on opening the map.
  - Trip planner: a failed plan ends with a message instead of a spinner for good, a walk-only option is no longer marked live, and very long street numbers are searched.
  - Settings: a failed export says so, leaving the import picker without a file says nothing, and the fare from an import shows at once.

## Installation

Download either APK (they are the same file) and install it over 4.6.0: it is signed with the same key, so your cards, stops, settings and cached maps stay. From 4.6.0: Settings > About > **Check for updates**. To be safe, export your data first (Settings > Export data).
